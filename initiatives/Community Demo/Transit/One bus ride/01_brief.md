# Brief — One bus ride

**Status:** Approved (demo)  
**Initiative:** Community Demo · **Project:** Transit  
**One-liner:** A one-page things-to-do guide for a single CapMetro MetroRapid 801 trip using only public schedule and place data.

## Problem

Someone new to Austin wants one bus ride that feels intentional, not a random transfer puzzle. They need a bounded plan: where to board, what to see, when to hop off.

## Hypothesis

Public CapMetro schedule pages plus well-known public places are enough to draft a useful guide without private partner data.

## Audience

First-time CapMetro riders and workshop attendees watching a harness demo.

## Success

- Guide fits on one page
- Uses only public CapMetro + public POI facts
- Shows a finished harness project waiting at its last approval gate

## Out of scope

Real-time trip planning apps, payments, accessibility audits of CapMetro, private venue deals.

## Effort

Hours, not weeks. Teaching prop, not a product.

## Open questions

None for the demo. Route locked to MetroRapid **801** (North Lamar / South Congress).

## Recommendation

Build the guide through the harness stages so the class can see Brief → Launch as a coherent trail.
